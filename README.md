# Kafala — Orphan Sponsorship Platform

An Arabic, RTL-first platform for orphan sponsorship and donations. Twelve complete pages covering orphan profiles, a full sponsorship & checkout flow, a user dashboard, authentication, blog and FAQ — built with clean, framework-free code.

## ✨ Features

- 12 complete pages, from donation to user dashboard
- Full sponsorship & checkout flow
- Login, registration, blog and FAQ
- Modern RTL design that conveys the project's human impact

## 🛠 Tech Stack

**HTML · CSS · JavaScript**

## 🚀 Getting Started

```bash
npx serve .
```
