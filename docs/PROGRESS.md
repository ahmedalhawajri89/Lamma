## ⚠️ ما يجب معرفته قبل التعديل

**١. مجلد بناء اللوحة اسمه `admin-app` والمسار `/admin`. الاختلاف مقصود.**
لو تطابقا لصار `public/admin` مجلداً موجوداً، وخوادم الويب تخدم المجلدات ساكنةً
قبل أن تصل الطلبات إلى لارافل. وأسوأ صوره: مع `index.html` داخله يمشي خادم PHP
في المسار فيجعل `SCRIPT_NAME=/admin/index.html` و`PATH_INFO=/orphans`، فيقتطع
Symfony الـ baseUrl ويرى لارافل `/orphans` — **فيعرض صفحة الموقع العام مكان
اللوحة، بلا خطأ ولا أثر**. التفصيل في `admin/vite.config.js`.

**٢. جذر موجّه Vue ليس `import.meta.env.BASE_URL`.**
ذاك يتبع مكان الأصول (‏`/admin-app/`) لا مكان التطبيق (‏`/admin`).

**٣. استعمل `127.0.0.1` لا `localhost` مع خادم التطوير.**
على ويندوز يُحلّ `localhost` إلى `::1` أولاً وخادم PHP المدمج على IPv4 وحده،
فينتظر كل طلب ثانيتين. لوحة Vue في التطوير تمرّ بوسيط Vite فلا يمسّها ذلك.

**٤. الاختبارات تعمل على MySQL لا SQLite** (‏`phpunit.xml`) — المخطّط يعتمد على
عمود مُولَّد وفهرس FULLTEXT.

**٥. `php artisan serve` أحادي الخيط.** طلبات الصفحة تصطفّ خلف بعضها، فمهلات
اختبارات المتصفح مضبوطة على ذلك. php-fpm يخدمها متوازيةً.

**٦. `GUARDIAN_ID_PEPPER`** في `.env` ما يزال `change-me-in-production`.

**٧. النشر صار واحداً.** لا Vercel ولا `vercel.json` بعد الآن: كل شيء داخل
`api/public`، فالمشروع كله يُنشر كتطبيق لارافل واحد. ولم يُختبر نشر فعلي بعد.

## 🐞 عيوب حقيقية كشفتها الاختبارات وأُصلحت

هذه ليست قائمة إنجازات بل تذكير بما يتكرر:

| العيب | كشفه |
|---|---|
| طلبات البيانات العامة تستبدل جلسة الكافل بجلسة ضيف فتطرده من لوحته | Playwright |
| النموذج قابل للإرسال قبل أن يربطه JS، فكلمة المرور تذهب لشريط العنوان | Playwright |
| `incrementQuietly` محمية في لارافل ١٢ — كل فتح لمقال كان يسقط | PHPStan |
| `VerifyOrphan` و`CancelSponsorship` واعتماد الصرف تُسند حقولاً غير مصرَّح بها | Pest |
| الكفالة المعلّقة لا تُحتسب، فيحجز كافلان الطفل نفسه كاملاً | Pest |
| شريحة «مكتمل» في مخطط التمويل صفرٌ أبداً | لقطة شاشة |
| كل الدفعات لها `created_at` واحد — Carbon قابل للتغيير بالمرجع | لقطة شاشة |
| علاقة `siblings` تعرض الطفل ضمن إخوته | لقطة شاشة |
| البحث بالمعرّف لا يعمل: FULLTEXT على الأسماء لا يغطّي `KFL-1042` | Playwright |
| `'fx_rate' ?? 1` — الـ `??` داخل الوسيط، والعمود غير موجود أصلاً | PHPStan |
| `response()->file()` لا يرسل جسماً مع حالة غير ناجحة — صفحة ٤٠٤ بيضاء | فحص يدوي |
| دالة عامة في `routes/web.php` تُلقي `Cannot redeclare` لأن الملف يُحمَّل لكل اختبار | Pest |
| حدّ الزائر ٦٠ طلباً/دقيقة يكفي ١٥ صفحة فقط بعد أن صارت كل صفحة تُصدر ٢–٤ طلبات | Playwright |

## 🔍 تدقيق الواجهة الأمامية — ٣٠ أغسطس ٢٠٢٦

مسحٌ للصفحات الخمس عشرة بحثاً عن روابط ميتة وأقسام تَعِد بما لا تفعل.
ما وُجد أُصلح كلّه:

| العيب | لماذا كان يهمّ |
|---|---|
| **«نسيت كلمة المرور» تكذب** — نموذج بلا `data-action` يمرّ بفرع المحاكاة فيعرض «أرسلنا لك رابط» ولا يُرسل شيء | من ينسى كلمته يُقفَل خارج حسابه وينتظر بريداً لن يأتي. أخطر ما وُجد. |
| **لا صفحة مقال** — كل عنوان `href="#"` رغم أن `/public/posts/{slug}` جاهز | المدونة تُنشر ولا تُقرأ |
| **جسم المقال نسخة من مقتطفه** في البذرة | «المقال» جملة واحدة — عيبٌ لا تكشفه إلا صفحة تعرضه |
| **زرّ «تحميل مقالات أقدم» بلا معالج** | زرّ ميت يوحي بأن الموقع معطّل |
| **`[hidden]` لا يعمل** — `display` في `.btn` يهزم قاعدة المتصفح ذات الأولوية الصفرية | `el.hidden = true` بلا أثر في كل المشروع، لا هنا وحدها |
| **أزرار Google/Apple** بلا OAuth في الخادم ولا معالج في الواجهة | ثلاثة أزرار تَعِد بما ليس موجوداً — حُذفت |
| **خطأ خادم على حقل مخفي يضيع صامتاً** | يُضغط الزرّ فلا يحدث شيء ولا يُقال لماذا |
| **أرقام لاتينية في النثر العربي** و«2 دقائق» | العربية تُعدّ بأربع صيغ لا بواحدة |
| **أغلفة المقالات ‏403** — البذرة تكتب المسار ولا أحد يضع الملف في `storage` | كل نسخة جديدة من المستودع تبدأ بمدونة بلا صور |
| **الشفافية تعرض ‎$2,140,000‎ مكتوباً** والصرف الحقيقي ‎$35,401 | على الصفحة التي كل دعواها أن الرقم يُتحقَّق منه |

**ملفّان جديدان:** `post.html` و`reset-password.html`.

### باقٍ من التدقيق

- **أربعة روابط «تحميل PDF» في `transparency.html` تشير إلى `#`** — الميزانية
  المدقّقة والتقرير السنوي وتقرير الزكاة والتراخيص. لا جدول مستندات في قاعدة
  البيانات ولا نقطة API لها. القرار مؤجَّل: إمّا جدول `documents` + رفع من
  اللوحة، أو حذف البطاقات حتى توجد الوثائق. تركها `#` ليس خياراً على صفحة
  الشفافية بالذات.

## 📌 ما لم يُنجَز بعد

### نماذج الإنشاء والتعديل في اللوحة ← الفجوة الأكبر

الـ API يدعمها كلها ومختبَرة، ولا واجهة لها: إنشاء يتيم وتعديله ورفع صورته،
ورفع مستندات التحقق (**وهذه تمنع توثيق أي ملف جديد**)، وإنشاء أسرة، وتسجيل
صرف، وتسجيل دفعة يدوية واستردادها، وكتابة تقرير، وتسجيل زيارة، وإنشاء موظف،
وتحرير المحتوى، وشاشة الإعدادات.

### ما تبقّى غير ذلك

- **بوابة دفع حقيقية.** `checkout.html` ما يزال يحاكي، و`RecordPayment` جاهزة
  لاستقبال webhook من بوابة فعلية.
- **إرسال البريد.** مسار «نسيت كلمة المرور» صار كاملاً ومختبَراً، لكن
  `MAIL_MAILER=log` — الرسالة تُكتب في `storage/logs/laravel.log` ولا تُرسَل.
  ينقصه ضبط SMTP وحده. وكذلك تأكيد الاشتراك في النشرة.
- **رفع الصور من اللوحة.** المسار موجود في `OrphanController`، ولا واجهة له بعد.
- **i18n.** ‏`users.locale` موجود والبنية تحتمله، ولا ترجمة إنجليزية بعد.
- **لم يُختبر نشر فعلي.** المشروع صار تطبيق لارافل واحداً، وينقصه تجربته على
  خادم حقيقي (‏Nginx أو Apache) لا على `artisan serve`.
